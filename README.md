# Preny AI · Trình chiếu

Trang trình chiếu demo Preny AI chatbot theo từng ngành: menu chọn ngành → slide → demo AI chat → slide kết.

- Mở trang: `trinh-chieu.html` (link gốc của trang web tự chuyển sang đây).
- Phím: → tiếp · ← lùi · F toàn màn hình · M về menu · bấm thanh tiến độ để nhảy tới slide.
- Mở thẳng một ngành: `trinh-chieu.html#kb=thoi-trang-tc` (thêm `&demo` để vào thẳng phần chat).

Tên shop, khách, giá, số điện thoại trong các kịch bản là dữ liệu minh họa. Ảnh: Unsplash, Pexels.
